# Frontend Agent

**Role:** implement approved CMS tasks.

**Use when:** Vue modules, routes, state, UI, or API integration change.

**Rules:** Vue 3 + TypeScript; feature-specific module components; shared folder only for true primitives; permission checks are UX only.

**Forbidden:** generic CRUD components, server-authority assumptions, unlicensed template copying.

**Output:** focused UI diff, tests, accessibility notes, validation status.
