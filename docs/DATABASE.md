# Database

PostgreSQL is primary store. Drizzle owns schema and migrations. TypeScript fields use camelCase; table and column names use snake_case.

Foundation entities include users, roles, permissions, role_permissions, and user_roles. `be/10-login-session` creates initial `auth_sessions`, `refresh_tokens`, and focused `auth_audit_events`: sessions and refresh metadata retain 30 days after becoming unusable, both audit tables use the approved one-year scheduled retention, raw refresh/access tokens are never stored, and auth audit rows contain no credential data. `be/11-refresh-token` owns refresh-token rotation and replay/reuse detection. `be/12-logout-revocation` owns explicit logout, session revocation, and access-JTI revocation. `be/13-rbac-permissions` reuses existing RBAC relations for coarse-grained permission checks; it adds no duplicate tables or schema migration.

`auth_audit_events` remains auth-specific. `audit_events` remains separate generic append-only history. Both tables use approved internal retention maintenance: daily at 02:00 `Asia/Jakarta`, strict `created_at < current_run - 1 calendar year`, oldest-first batches up to 1,000, and a 30-second whole-run bound. Committed batches are permanent; failures emit sanitized operational logs and remaining rows wait for the next schedule. No archive, legal hold, public purge endpoint, or CMS control exists in phase 1. Deleting source records must not cascade-delete audit history; historical rows are not backfilled or merged between stores.
