# fe/04-theme-design-system — Minimal CMS UI Foundation

Task ini dipersempit menjadi UI foundation minimum untuk shell, login, auth state, denied, dan Not Found. Token semantic minimal untuk warna, spacing, radius, dan typography sudah dibuat di `apps/cms/src/styles.css` lalu dipakai shell, Home, Login, dan Not Found. Tidak ada branding, dark mode, font eksternal, atau library baru.

Status sekarang `Implemented — verification incomplete`: test, lint, typecheck, dan build lulus. Browser verification pada viewport wajib serta review visual manusia belum dijalankan, jadi task belum boleh dianggap selesai.
