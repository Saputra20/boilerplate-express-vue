# be/28-user-management — User Management Contract

Task ini mendefinisikan keputusan yang diperlukan sebelum CMS dapat mengelola user. Login, session, refresh, logout, dan current identity tetap menjadi tanggung jawab auth yang sudah ada.

Belum ada endpoint atau UI user-management. Field, status, role assignment, password/invitation, pagination, permission, dan audit masih menunggu approval manusia.
